# Bilibili + douyin auto pause.rar
## 1. function
- Remove the triangles when Bilibili and Douyin on Edge web version are paused.
- When using Bilibili and Douyin on the Edge web version, dragging the progress bar while paused will no longer trigger automatic playback.
## 2. use
Load it via the Tampermonkey script in your browser.

# CodeCommentsV2.2.rar
## 1. function
- Code comments are stored separately in JSON files and will no longer pollute files such as .cpp/.c/.h.
## 2. use
In VS Code :
2.1. Open the Extensions panel with Ctrl+Shift+X.
2.2. Click the ... (More Actions) menu at the top right.
2.3. Select Install from VSIX....
2.4. Choose the codecomments.vsix file.
